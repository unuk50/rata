# Notes for coding agents

Read these before you change code in this repo:

- `.claude/skills/rata-contributing/SKILL.md`: each change links an issue or a product direction, goes through a pull request, and has a DCO sign-off.
- `.claude/skills/rata-design/SKILL.md`: UI rules (when present).
- `docs/product/`: where the product goes. `docs/architecture.md`: how it works.
- `CONTRIBUTING.md`: money, event and privacy rules.

Write docs, issues and pull requests in ASD-STE100 (Simplified Technical English).
