# Trademark policy

The code is open source. The name **Rata** and the Rata logo are not.

You may:

- Say that your project is "based on Rata" or "a fork of Rata".
- Use the name to refer to this project in articles, talks and reviews.

You may not, without written permission:

- Call a fork, a hosted service or an app store listing "Rata", or use a name that people can confuse with it.
- Use the Rata logo for your own product.
- Suggest that the Rata project supports or approves your product.

If you fork Rata and run it for other people, please change the name and the logo. Ask in GitHub Discussions if you are not sure.
